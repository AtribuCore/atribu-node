# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `@atribu/node`, please report it
privately so we can investigate and ship a fix before public disclosure.

**Email:** [security@atribu.app](mailto:security@atribu.app)

Please include:

- A description of the issue and its impact.
- Steps to reproduce (proof-of-concept code, if relevant).
- The affected package version(s).
- Any suggested remediation, if you have one.

We aim to acknowledge reports within 2 business days and to ship a fix or
mitigation within 7 days for high-severity issues.

Please do **not** open a public GitHub issue or pull request for security
problems — that exposes other users to risk before a fix is available.

## Scope

In scope:

- The `@atribu/node` npm package and everything published from this repo.
- Webhook signature verification, OAuth helpers, admin client, and the
  Next.js adapter exported from `@atribu/node/*`.

Out of scope (report to [security@atribu.app](mailto:security@atribu.app)
anyway, but they're tracked separately):

- The Atribu hosted API at `atribu.app`.
- The Atribu Tracker SDK (see [`atribu-tracker`](https://github.com/AtribuCore/atribu-tracker)).
- Third-party dependencies — please upstream first; we'll roll forward.

## Supply Chain

Releases ship with **Sigstore provenance attestations** generated by
GitHub Actions OIDC trusted publishing. You can verify any release with:

```bash
npm audit signatures
```

The provenance proves the published tarball was built from the commit
referenced by the corresponding `v*` Git tag in this repository, by the
GitHub Actions workflow at `.github/workflows/publish.yml`.
